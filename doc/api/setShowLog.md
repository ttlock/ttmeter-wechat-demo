# 通通水电表接口说明-设置日志输出开关及回调方法  

## 方法
```
    function setShowLog(open: boolean, callback: (...args: any | void) => void): void
```

### 功能描述   
 设置日志回调开关及回调方法  

### 版本支持   
 插件版本 **0.0.3** 开始支持  

### 参数说明 
 |PARAMS    |TYPE                       |REQUIRED      |DESCRIPTION|
 |----------|---------------------------|--------------|-----------|
 |open      |boolean                    |Y             |是否启用日志回调|
 |callback  |(...args: any) => void     |Y             |日志回调方法|  

### 返回值
 void
