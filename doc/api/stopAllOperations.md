# 通通水电表接口说明-强行中断所有蓝牙操作  

## 方法
```
    function stopAllOperations(): Promise<TTMeterError>;
```

### 功能描述   
 停止所有蓝牙操作，并强制退出忙碌状态      

### 版本支持   
 插件版本 **0.0.4** 开始支持  

### 特殊说明   
 若设备正在执行连接操作，该接口无法停止蓝牙连接，但强制退出忙碌状态，可进行其它蓝牙操作 

### 参数说明  
 无

### 返回值
 Promise<[TTMeterError](../错误码说明.md)>
